# Font licences

All three families are self-hosted here rather than loaded from the Google Fonts CDN,
so no visitor IP is transmitted to a third party on page load. All are licensed under
the **SIL Open Font License 1.1**, which permits redistribution and web embedding.

| Family | Used for | Designer | Source |
|---|---|---|---|
| Newsreader | Display / headings | Production Type | https://github.com/productiontype/Newsreader |
| Archivo | UI, labels, data | Omnibus-Type | https://github.com/Omnibus-Type/Archivo |
| Amiri | Arabic | Khaled Hosny | https://github.com/aliftype/amiri |

Full OFL text: https://openfontlicense.org

Files are generated — re-run the fetch script rather than hand-editing `../fonts.css`.
Newsreader and Archivo are variable fonts served as a single file per subset across
their whole weight range; Amiri is static.
